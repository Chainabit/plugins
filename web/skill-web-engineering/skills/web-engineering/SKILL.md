# Web engineering

Start with information architecture and semantic HTML landmarks, meaningful headings, keyboard operation, focus, labels, alt text, contrast, reduced motion, and usable error states. Design responsive layouts from content constraints with readable typography and robust interaction at narrow and wide viewports.

Choose assets deliberately: local or authorized sources, useful fallbacks, correct loading behavior, and no secrets in client code. Consider browser compatibility, performance budgets, caching, image dimensions, script cost, SEO metadata, canonical URLs, and progressive enhancement. Frameworks may change implementation, not these quality floors. Validate only framework-independent web behavior.
